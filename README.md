# Exploratory_Data_Analysis_Project --Iyowu-Esther
Exploratory data analysis (EDA) of a sales dataset using Excel to uncover trends, patterns, and business insights.

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) performed using Microsoft Excel. The analysis was completed in a single Excel Workbook containing multiple sheets for cleaned data, pivot tables, descriptive statistics, pivot tables, visualization, and key summary.
The objective of this analysis is to transform raw business data into clear, non-technical, and actionable insights that support better decision-making around sales performance, marketing effectiveness, and operational efficiency.

> ** Note: ** Data cleaning was completed in a previous project phase to ensure the dataset was properly structured before analysis.

---

## Tools & Techniques Used
- Microsoft Excel
- Pivot Tables
- Charts & Graphs
- Descriptive Statistics ( Data Analysis Toolpak)
- Correlation Analysis

 ---

## Workbook Structure
Raw dataset 
The EDA Excel file is organized into the following sheets:
- **Cleaned Data** -> Processed dataset prepared for analysis
- **Descriptive Statistics** -> Summary metrics and distribution insights
- **Pivot Tables** -> Aggregated analysis of key business metrics
- **Visualizations** -> Charts representing trends and comparisons
- **Key Observation Summary** -> Final interpretations and actionable findings.

---

## Analysis Performed
  - Data exploration using pivot tables and aggregation techniques
  - Time-series analysis to identify sales trends and seasonality
  - Comparative analysis across products, payment methods, and marketing channels.
  - Correlation analysis to understand relationships between key variables
  - Data visualizations to communicate patterns clearly

---

  ## Key Insights & Results
  
  - **Top Products:** Chair ( Highest sales volume contributor)
  - **Best Payment Method:** Credit Card (Most preferred)
  - **Top Referral / Marketing Channel:** Instagram
  - **Peak Sales Month:** June 2024 ( Highest recorded sales period)
  - **Lowest Sales Month:** April 2023 ( Lowest revenue performance period)
  - **Total Orders:** 1,200
    
  - **Order Status Insight:** A notable number of Cancelled orders was observed, indicating a potential revenue leakage area that may require further investigation.
 
  - **Statistical Correlation:**
  - *Unit Price Vs Quantity (0.014553):* No strong linear relationship observed between price and quantity purchased.
  - *Quantity vs Total Price (0.615251):* Moderate to strong positive correlation, indicating higher revenue is driven by larger basket sizes.
